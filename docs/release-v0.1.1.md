# Coelhitos 0.1.1 — movimento e disparo revisados

## Alterações

- Coelho desenhado de perfil, olhando para o sentido em que anda.
- Locomoção quadrúpede, com corpo alongado e animação das patas dianteiras e traseiras.
- Salto avança automaticamente para frente quando não há direção horizontal; joystick diagonal direciona o salto.
- Toque curto em AÇÃO dispara enquanto o joystick continua movendo o coelho. Segurar AÇÃO com uma direção corre.

## Verificação

- Package: `com.coelhitos`
- Version: 0.1.1 (`versionCode 2`)
- Requer Android 6.0 ou superior; orientação horizontal.
- APK debug: `Coelhitos-v0.1.1-debug.apk`
- SHA-256: `4816a8455a34da0347527db6fd05eb0913815285510c53f51dd96e13b1cc7844`
